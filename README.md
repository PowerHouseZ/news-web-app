# News Web App 📰

## 🚀 Features

- Fetches real-time news articles from a public API  
- Displays headlines, descriptions, images, and links to full articles  
- Clean and minimal UI for easy reading  
- Responsive layout for desktop and mobile  
- Error handling for missing or invalid API responses  

---

## 🛠️ Tech Stack

- **HTML5** – structure and layout  
- **CSS3** – styling and responsive design  
- **JavaScript (ES6)** – API calls, async/await, DOM updates  
- **News API** – external data source for articles

## 📚 How It Works

1. The app sends a request to a public News API  
2. The API returns a JSON response containing article data  
3. JavaScript dynamically updates the DOM to display:  
   - Title  
   - Description  
   - Image  
   - Source link  
4. Users can scroll through the latest articles in a clean, readable layout
